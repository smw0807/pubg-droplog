## 문서 유지 기준

- 실행 명령·환경변수·운영 제약은 개발 안내에, 실제 실행 결과는 검증 기록에 둡니다.
- 검증 결과에는 날짜와 대상을 적고 합성 데이터, 저장된 실데이터, 외부 PUBG 호출을 구분합니다. 문서 편집만으로 과거 측정을 최신 검증으로 바꾸지 않습니다.
- PRD 본문의 초기 요구를 보존하고 후속 기능과 현재 구현 상태는 진행 상태·검증 기록에 연결합니다. 보관 프롬프트는 현재 작업 지시로 사용하지 않습니다.
- 로컬 서버의 실행 여부·개인 닉네임·리포트 UUID·비밀값을 지속적인 프로젝트 설정처럼 기록하지 않습니다. 실행 모드는 `/api/status`로 확인합니다.
