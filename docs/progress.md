## 후속 UI 개선 — 맵 이미지

- 사용자 제공 에란겔·미라마·론도·태이고 이미지를 홈 갤러리, 경기 목록 미리보기, 리포트 상단 배너에 적용했다.
- 맵 이름과 이미지 매핑을 중앙화하고 이미지가 없는 맵의 대체 표시를 제공한다. 기존 성적표·타임라인·검색·공유 흐름을 유지한다.
- lint·typecheck·build, 기존 Chromium E2E 15개, 360/768/1024/1440px 양쪽 테마, 생산 Nitro 이미지 전송·리포트 렌더링 검증을 통과했다. 상세 결과는 `docs/validation.md`의 후속 UI 검증에 기록했다.

## 인계 상태

- `pnpm lint`, `pnpm typecheck`, 단위 테스트 89개, DB 통합 테스트 10개, Chromium E2E 15개를 통과했다. 생산 빌드 및 실제 Node 경로 smoke도 통과했다. 최종 명령·측정은 `docs/validation.md`에 기록한다.
- localhost:3100 개발 서버와 이 프로젝트 전용 PostgreSQL이 실행 중이다. 작업 중 구성된 로컬 `.env`를 보존했다. 종료 전 키가 설정된 것을 확인하여 사용자가 제공한 카카오 닉네임으로 T07 읽기 전용 검증을 추가했다. 비밀값은 출력하거나 Git에 추가하지 않았다.
- 실행·검증·live 전환 절차는 README에 있다. `SquadMate` 검색 또는 예약 샘플 링크로 시작한다.
- 다음 작업은 T07의 나머지 범위: 실제 일반전 `official` 매핑, Steam과 나머지 듀오/스쿼드 조합을 확인하는 것이다. 카카오에서 `competitive + squad`는 랭크 스쿼드로 실검증했으며 나머지 조합을 확대 해석하지 않는다.
- 운영 배포 전에는 단일 프로세스 가정, 프록시 IP 신뢰, 보관·백업 정책과 실제 기기 클립보드를 확인해야 한다.

구현 완료와 운영 검증 완료는 구분한다. 현재는 **로컬 데모·자동 검증 기준 구현 완료**, 카카오 랭크 스쿼드 실연동 확인, 나머지 조합과 선택 운영 환경은 미검증이다.
