## 초기 PRD 이후 변경

[PRD 1.1](PUBG_SQUAD_REVIEW_PRD.md)은 초기 MVP 계약입니다. 이후 요청으로 맵 이미지와 사건 위치 지도를 추가했습니다.

- 분석 버전 2에서 역할별 좌표를 저장합니다. 기본 핀은 피해자·소생 대상 위치이고 선택한 사건의 행위자 위치를 구분합니다. 좌표가 없거나 유효하지 않아도 타임라인 사건은 유지합니다.
- `POST /api/reports/:reportId/upgrade`로 별도 ID의 새 버전을 생성·재사용합니다. 이전 버전 1 기록과 공유 URL은 보존하며 생성·재시도와 같은 5회/분 제한을 적용합니다.
- 에란겔·미라마·태이고는 핀을 지원합니다. 론도는 이미지가 있지만 좌표 범위가 확인되지 않아 핀을 표시하지 않습니다. 이동 경로·재생은 미구현입니다.
- 실제 에란겔 한 경기에서 주요 21개·전체 607개 사건의 대상 좌표를 확인했습니다. 다른 맵의 실경기 좌표 검증으로 확대하지 않습니다.

## 작업을 이어갈 때

1. 현재 Git 변경과 [개발 안내](development.md)를 확인합니다. 위 완료 상태만으로 테스트 재실행이나 외부 조회가 필요한 것은 아닙니다.
2. 로컬 `.env`는 Git에 없으므로 모드를 가정하지 말고 `/api/status`를 확인합니다. 초기 예시는 demo이며 실행 중인 서버는 사용자가 바꾼 모드일 수 있습니다.
3. 브라우저 회귀 테스트에는 별도 demo 서버를 사용합니다. 실제 PUBG 검증과 합성 테스트 결과를 구분해 기록합니다.

서버 실행 여부·개인 닉네임·리포트 UUID를 인계의 전제 조건으로 두지 않습니다. 공개 배포는 아직 수행하지 않았습니다.
